    3 · How it works

    Five stages, one of them human

    01
    Discover
    Seed hint URL, doc-path patterns and model-proposed URLs — guesses at where docs live.
    02
    Fetch
    Real HTTP, with retries, nav-chrome stripping and a second hop into auth/access pages. 404s die here.
    03
    Extract
    Gemini, schema-constrained, over the fetched text only. Each field must quote a line, verified as really present.
    04
    Verify
    A second model re-reads each answer adversarially: does the page confirm this, and is it access or only usage docs?
    05
    Re-run
    Failure patterns patch the prompt; all 100 run again as Pass 2 and are re-scored.

    Where a human was required: the ground truth. A person opened the real docs and pricing pages for 20 stratified apps and marked each field correct, incorrect or partial. Everything else on this page is measured against that call — an agent grading its own homework cannot establish whether it is right.
