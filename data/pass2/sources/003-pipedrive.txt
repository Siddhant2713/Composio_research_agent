Pipedrive API Reference and Documentation
API Reference
This reference helps you implement the RESTful Pipedrive API. This API uses a JSON format for output and is capable of handling CORS (Cross-Origin Resource Sharing) requests. The API is stateless – all requests are validated against an API token. The API token can be
obtained
manually from the Pipedrive app.
OpenAPI 3
You can click on the "Run in Postman" button below to interact with our API. We have a
tutorial
for using Pipedrive API in Postman or Insomnia, but if you prefer to use a different tool, you can always import our OpenAPI 3 specification files (available for both
v1
and
v2
APIs) into your tool of choice. See
this
article to learn more about Pipedrive API v2. Keep in mind that we'll occasionally update our OpenAPI 3 specification files, so you might need to re-import them from time to time. For ready-to-use SDKs, read below under "Client libraries".

extension points

Changelog
.
