Perform API calls with API key
API keys use
HTTP Basic client side authentication
.
Basic authentication is a simple authentication scheme built into the HTTP
protocol. To use it, send your HTTP requests with an Authorization header that
contains the word Basic followed by a space and a base64-encoded string composed
of an api key followed by a colon. The API key acts as the username and the
password is always empty.
cURL example
Example cURL request with an api key.
curl
https://api.close.com/api/v1/me/
-u
yourapikey:
Notice the ’:’ at the end of the api key. This is used because the key is sent
as the username with a blank password.

Close uses forms and automated email sequences, task reminders, and customizable workflows to keep follow-ups on track. You can trigger actions based on lead behavior—like new lead, email opens, or missed calls—so your team stays on top of every opportunity without manual tracking.
Can I customize automation rules to fit my sales process?
Absolutely. Close's automation features are fully customizable. You can set up workflows based on your unique sales pipeline and lead behaviors.
How does Close's automation compare to traditional CRMs?
Unlike traditional CRMs that require heavy manual input, Close's automations are simple to manage, but powerful in action. You can run both communication Workflows (where you follow-up with leads via call, email, text, and more) and back-end CRM automations that keep your data clean, all in one place.
Does Close's automation work with my existing tools?
Yes. Close integrates with popular tools like Zapier, Slack, and Gmail, making it easy to connect your automation workflows across your sales stack.
How difficult is it to set up automation in Close?
Setting up automation is simple, with intuitive workflows and templates to get you started. No technical skills required—just set your triggers, and Close handles the rest.
Do any of Close's automation features cost extra?
All of Close's core automation features—workflows, task automation, and outreach sequences are included at no extra cost on the Professional (Growth) and higher plans.
