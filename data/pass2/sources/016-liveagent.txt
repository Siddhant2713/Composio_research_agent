Type
Description
datetime
valid format: YYYY-MM-DD HH:MM:SS.
Note: values are in time zone defined in '/accounts/settings.php' or in "GMT" timezone by default.
text
could be any string or empty
constlist
could be only one instance of finite set. Possible values are named in specifice field description.
int
integer value greater or equal to zero.
array
list of entities. All entities have the same column definition
list
list of entities. Every entity has its specific column definition.
opdatetime
datetime with operator. This field has the same format as 'datetime' except you can use various operators with it.
Possible operators:
eq:
equals, example 'eq:2009-11-12 05:02:01' or just '2009-11-12 05:02:01'
gt:
greater than, example 'gt:2009-11-12 05:02:01'
lt:
less than, example 'lt:2009-11-12 05:02:01'
gte:
greater than or equals, example 'gte:2009-11-12 05:02:01'
lte:
less than or equals, example 'lte:2009-11-12 05:02:01'
btw:
between, example 'btw:2009-11-12 05:02:01,2010-10-11 04:01:59'
note: if you do not enter any operator,  'eq' will be used as default.
