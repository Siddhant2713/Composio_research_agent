Credit unit

What the install gives you
Firecrawl skills cover three categories.
init
installs CLI and workflow skills. Run
firecrawl setup build
for build skills. Each segment lives in its own repo so it can evolve independently:
firecrawl/cli
— CLI skills for live web work
firecrawl/skills
— build skills for app integration
firecrawl/firecrawl-workflows
— workflow skills for repeatable deliverables
CLI skills
— for live web work during an agent session:
Skill
Purpose
firecrawl
Overall CLI command workflow
firecrawl-search
Search the web and discover pages
firecrawl-scrape
Extract clean content from a known URL
firecrawl-interact
Interact with scraped pages using prompts or code
firecrawl-crawl
Bulk-extract content from an entire site
firecrawl-map
Discover all URLs on a domain
firecrawl-agent
Run autonomous web data gathering with a job
firecrawl-monitor
Detect site changes and get notified
firecrawl-parse
Parse local documents into markdown
firecrawl-download
Download a site as local files
firecrawl-research-index
Search papers, read passages, and follow citations
firecrawl-developer-index
Search issues, pull requests, READMEs, and docs
The install above includes both index skills. To add just the paper-search one to an existing setup — worth doing when the work is biomedical or scientific literature — run:
npx
skills
add
firecrawl/skills@firecrawl-research-index
